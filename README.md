# Multimodal ML for Wireless Communications

An interactive project exploring the application of multimodal machine learning techniques to wireless communication systems.

This repository contains interactive HTML-based simulations developed to demonstrate wireless communication scenarios, multimodal feature fusion, and machine learning based prediction techniques.

## Project Overview

Modern wireless communication systems increasingly use information from multiple sources such as communication signals, environmental information, mobility data, and other contextual features.

This project explores how machine learning can combine and utilize such information for intelligent wireless communication applications.

The repository provides interactive simulations that allow users to visualize and explore different wireless communication and machine learning concepts directly through a web browser.

## Interactive Simulations

The project currently includes the following simulations:

### 1. LOS / NLOS Simulation

An interactive simulation for exploring Line-of-Sight (LOS) and Non-Line-of-Sight (NLOS) wireless communication scenarios and their impact on wireless signal propagation.

[Open LOS / NLOS Simulation](https://dhyani-lakshay.github.io/Multimodal-ML-for-wireless-communications/los_nlos.html)

### 2. V2C Simulation

An interactive simulation focused on Vehicle-to-Cloud (V2C) communication concepts and their application in intelligent wireless communication systems.

[Open V2C Simulation](https://dhyani-lakshay.github.io/Multimodal-ML-for-wireless-communications/v2c.html)

### 3. C2V Simulation

An interactive simulation demonstrating Cloud-to-Vehicle (C2V) communication concepts and their relationship with machine learning based wireless communication systems.

[Open C2V Simulation](https://dhyani-lakshay.github.io/Multimodal-ML-for-wireless-communications/c2v.html)

### 4. Multi-Modal Feature Fusion

An interactive demonstration of multimodal feature fusion for wireless communication applications.

The simulation illustrates how information from multiple modalities can be combined to improve the representation and processing of wireless communication data.

[Open Multi-Modal Feature Fusion Simulation](https://dhyani-lakshay.github.io/Multimodal-ML-for-wireless-communications/Multi_Modal_Feature_Fusion.html)

### 5. Multimodal Deep Learning Based Beam Prediction

An interactive simulation demonstrating multimodal deep learning based beam prediction for wireless communication systems.

The simulation explores how multiple sources of information can be utilized with deep learning techniques for predicting suitable communication beams.

[Open Beam Prediction Simulation](https://dhyani-lakshay.github.io/Multimodal-ML-for-wireless-communications/multimodal%20deep%20learning%20based%20beam%20prediction.html)
